## 每个重要代码块的目的

| Notebook块 | 代码位置 | 为什么存在／怎么调试 |
|---|---|---|
| 01 路径与指纹 | Notebook | 确认两个ZIP来源。哈希不符先检查输入版本，不能为跑通而删断言。所有写操作限定Stage 2目录 |
| 02 候选读取 | extraction.read_sources | 从NUM分块抽取并保留TAG定义，读取Stage 1资格审计。查看raw候选有没有所需tag/version，先区别没有标签与过滤后没有值 |
| 03 重复QA | extraction.precision_interval / deduplicate | 相同事实可能多次表示。检查默认iprx是否唯一、上下文是否一致、精度区间是否相交；冲突应进入review，不取首行掩盖问题 |
| 04 财务选择 | extraction.select_financials | 逐申报逐变量检查币种、期间、无维度、主报表列示及版本。查看candidate_tags_json定位冲突；assets是存量，不能要求qtrs=4 |
| 05 研究表 | analysis.construct_sample | 一对一合并并构造指标、对数及互斥排除原因。NA比较很容易错误变成False；本实现显式恢复缺失标签 |
| 06 样本可行性 | analysis.sample_report | 统计每个筛选步骤及各样本的正、零、负、缺失。不要先看回归星号再挑样本 |
| 07 描述统计 | analysis.descriptive | 看变量分布和缺失，对比合格／亏损／最终样本。亏损指标在亏损样本恒定，因此相关系数为空 |
| 08 模型 | analysis.fit_logit | 检查类别数、满秩、分离和收敛；失败就记录原因。输出系数、稳健误差、置信区间和平均边际效应 |
| 09 输出断言 | Notebook | 防止重复公司期间、漏排BigBear/iWallet、缺失填零和跨期间拼接；断言通过不等于全体会计语义已验证 |
| 10 原文件保护 | Notebook | 将运行前后实际存在的原文件指纹逐一比较，并列出缺失文件，避免空检查被误称为全量通过 |

## 回归怎么读

系数衡量对数胜算，不是概率百分点；`exp(beta)`是协变量增加一单位对应的胜算比。
本模型的单位是自然对数美元，金额翻倍对应`ln(2)`的变化。
平均边际效应是样本各行概率导数的平均值，乘100可换成每个log单位的概率百分点。
它不是资产增加导致支付税款的因果效应。规模、行业、跨国经营、历史亏损和披露选择可能共同影响结果。

M1与M2的差异提示样本选择；M2与M3在同一观测上比较，反映加入收入变量的变化。
S1用更宽的收入代理样本，不能与M3的系数变化直接解释为一个纯变量效应。
S2只是部分接近论文筛选，既没有完整法律实体筛查，也没有原论文的多年机制变量。
