McFadden伪R²=0.195209。模型收敛，设计矩阵满秩；线性规划未检出完全／准完全分离。
稳健协方差另外用score和Hessian构造sandwich交叉验证，避免只依赖标签声称“robust”。

平均边际效应：资产对数0.021524（SE=0.015458，95%CI[-0.008772,0.051821]），
收入对数0.041168（SE=0.014677，95%CI[0.012402,0.069934]）。
含义为每一个自然对数单位的平均概率导数，不是增加一美元的效应，也不是因果效应。

条件于资产规模，收入较大的亏损企业更常支付正现金税；资产在同时控制收入后证据较弱。
这不能证明收入“导致”付税，不能替代跨国经营、州税、税会差异与历史亏损机制分析。
完整描述统计、相关矩阵和其他实际估计模型均已导出，不只展示主模型。

## 与论文能否比较

亏损定义与税款正负的Extensive Margin问题可以作概念比较。论文的36,989个亏损firm-years
来自1988–2023 Compustat多年样本，并使用多种机制变量、行业与年份效应及不同SIZE定义。
本研究用SEC单月申报批次、两个对数特征和不同样本筛选，不能比较系数是否“复现”。
本样本的正现金税比例与论文约68%的差别也不能作为统计拒绝或确认。
详见replication_comparison.md。
