# Source modules

- `tax_data_utils.py`: Stage 1 extraction, duplicate review, eligibility, and reconciliation helpers.
- `extraction.py`: Stage 2 SEC financial-variable extraction and conservative fact selection.
- `analysis.py`: Stage 2 sample construction, descriptive statistics, Logit estimation, and diagnostics.
- `validate_stage1_outputs.py` / `validate_stage2_outputs.py`: post-run output checks.
